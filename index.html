8 层能力栈覆盖设计全流程。每一层都基于下层产出，形成完整的工具链。

设计决策

把页面截图丢进去，它会像设计总监一样告诉你哪里不对——配色太花、留白不够、层级混乱、文案难懂。不用学设计理论，它直接给答案。

帮我看看这页面配色怎么改动效该不该加

设计系统

统一所有页面的颜色、字体、间距。给整个项目建一套"设计宪法"，之后不管加多少新页面，看起来都是同一款产品。

统一项目配色建暗色模式定字体间距

动效实现

让页面"活"起来——按钮按下有弹性、卡片滑入自然流畅、加载时有呼吸感。不需要写复杂动画代码，告诉它想要什么感觉就行。

按钮加弹性反馈卡片滚入效果毛玻璃面板加载动画

视觉创建

给它一段文字或数据，还你一张配图、一份信息图、一个流程图。写文章需要封面？给。PPT 少张图？给。数据需要可视化？给。

安装

一条命令，30 秒搞定。

Git Clone（推荐，可随时 git pull 更新）

git clone https://github.com/ikevss/design-skillhub.git ~/design-skillhub
cd ~/design-skillhub && bash designer-setup.sh

离线包

tar xzf design-skillhub-*.tar.gz
cd design-skillhub-* && bash designer-setup.sh
安装后重启 AI Agent 无需 API Key 纯本地，不修改系统
