你能做哪些事

不用学设计，说出来就行

每个场景都是真实对话。你说左边的日常问题，它给你右边的结果。

你说的话
"帮我看看这个页面有什么问题"
刚做完一个落地页，总觉得哪里不太对劲，但具体说不上来。发给同事看也只会说"还行吧"。
不确定哪里有问题缺乏设计反馈
AI 做的事
10 项启发式评估 + 认知负荷分析 + 多角色走查。告诉你配色对比度不够、3 个按钮离太近误触风险大、正文行距太窄影响阅读。
配色方案建议层级优化行动清单
你说的话
"新做的几个页面跟之前的长得不像一家人"
项目越做越大，首页是蓝色调、设置页是灰色调、弹窗的按钮圆角有的 8px 有的 14px。每次加新页面都要翻旧页面抄样式。
风格不一致颜色/间距混乱
AI 做的事
扫描你现有的全部页面，自动提取出颜色、字体、间距、圆角统一成一套 Token。之后做新页面直接引用这套规范，再也不会出现"东拼西凑"的感觉。
自动提取Token全局统一
你说的话
"页面像 PPT 一样死板，一点动感都没有"
按钮按下没有反馈，切换页面是硬切，加载时只有白屏。想做动效但写动画代码太耗时，试了几次效果都不自然。
生硬死板不会写动效
AI 做的事
你只需要描述感觉："按钮按下要有弹性""卡片滑进来要自然""加载的时候别让用户干等"。它直接给你写好动画代码，缓动曲线、持续时间都调好了。
弹性按钮滚动入场加载过渡
你说的话
"这篇文章需要封面图，但找不到合适的素材"
翻遍了 Unsplash 找不到合适的图。公司没有设计师可以帮忙。自己用工具画的图拿不出手。
没图用素材不合适缺设计师
AI 做的事
描述你想要什么风格和主题，直接生成配图。数据分析报告需要图表？把数据给它，生成可视化。复杂流程需要说明？画出清晰的信息图。一句话的事。
封面生成数据图表信息图插图
你说的话
"明天要汇报，PPT 还是白板"
花 3 个小时做出来的 PPT 像实习生水平。排版对不齐、配色辣眼睛、每页长得都不一样。
做PPT耗时排版业余
AI 做的事
把你的内容大纲给它，整份 PPT 一键生成——每页都有精心设计的排版、配色统一、图表自动生成。支持导出可编辑的 pptx，不满意随时微调。
一键生成可编辑pptx21套模板
你做出来的页面
"组件样式很素，像没被设计过"
颜色各自为政、卡片没有层次感、数字用默认字体看起来廉价、按钮选了蓝色但跟整体不搭。自己觉得"能看"，但给客户看的时候心里没底。
颜色混乱无层级廉价感
AI 帮你改之后
统一品牌色、建立卡片层级（品牌色顶边 + 微阴影）、数字启用等宽字体不再跳动、按钮换成匹配的绿色。现在你觉得"能发给客户看了"。
品牌色统一等宽数字层次清晰
Getting started

安装

一条命令，30 秒。装完重启你的 AI 工具就能用。

Git Clone（推荐，可随时 git pull 更新）

git clone https://github.com/ikevss/design-skillhub.git ~/design-skillhub
cd ~/design-skillhub && bash designer-setup.sh

离线包

tar xzf design-skillhub-*.tar.gz
cd design-skillhub-* && bash designer-setup.sh
安装后重启 AI 工具 无需 API Key 纯本地，不修改系统

怎么说话

用你自己的话说就行

不用记任何命令。就像跟一个设计师同事对话。

你想做什么它会怎么做
"帮我看看这个页面有什么问题"跑一遍设计审查，给你改进清单
"配色有点奇怪，帮我调一下"分析当前配色 + 生成优化方案
"字体大小和层级帮我理一下"重新建立排版层级 + 间距规范
"帮我建一套统一的颜色和字体规范"自动生成完整的 Design Token
"这个组件动起来没感觉"按你的描述写动画代码
"帮我做暗色模式"生成完整的暗色主题方案
"这篇文章配张封面图"生成匹配内容的配图
"这份数据画个图表"自动选择合适的图表类型并生成
"帮我画个流程图"文字描述 → 流程图
"帮我生成一份 PPT"给出内容，输出完整 PPT
"检查一下无障碍有没有问题"WCAG 审计 + 修复建议
