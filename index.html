30 秒安装（Claude Code 默认）

其他 Agent 用户直接复制 skills/ 目录到对应路径即可，无需运行脚本。

方式 1：Git Clone（推荐，可随时 git pull 更新）

git clone https://github.com/ikevss/claude-code-designer-setup.git ~/design-skillhub
cd ~/design-skillhub && bash designer-setup.sh

方式 2：离线包

# 下载 design-skillhub-*.tar.gz 解压后：
cd design-skillhub-* && bash designer-setup.sh

✅ 安装后重启你的 AI Agent
✅ 无需 API Key · 纯本地安装 · 不修改系统配置
