# 默认现代风格

## 风格信息

- **名称**：默认现代风格
- **别名**：default-modern、现代风格、简约风格
- **适用场景**：通用 PPT、商务汇报、产品介绍、项目总结

## Style Lock

### 颜色系统

- **背景色**：#FFFFFF（纯白）
- **主色**：#2563EB（蓝色）
- **辅色**：#64748B（灰色）
- **强调色**：#F59E0B（橙色）
- **文字色**：#1E293B（深灰）
- **辅助文字**：#64748B（灰色）
- **边框色**：#E2E8F0（浅灰）

### 字体气质

- **标题**：思源黑体/PingFang SC，加粗，24-32pt
- **正文**：思源黑体/PingFang SC，常规，14-16pt
- **数字**：DIN/Roboto，加粗，48-72pt
- **标签**：思源黑体/PingFang SC，常规，12pt

### 构图语言

- **封面页**：大标题 + 副标题 + 简洁背景
- **内容页**：标题 + 2-3 个信息点 + 图表/图片
- **对比页**：左右分栏或卡片对比
- **流程页**：箭头连接的步骤
- **结论页**：核心观点 + 行动建议

### 图形元素

- **边框**：无边框或细线边框（1px）
- **卡片**：圆角 8px，阴影（0 2px 8px rgba(0,0,0,0.1)）
- **分割线**：细线（1px），#E2E8F0
- **图标**：线性图标，与主色一致

### 信息密度

- **封面**：标题 + 副标题，无其他信息
- **内容页**：1 个标题 + 2-3 个短信息点
- **每页最多**：3 个主要信息块

### 负面约束

- 不使用渐变背景
- 不使用 3D 效果
- 不使用花哨装饰
- 不使用过多颜色（最多 3 种）
- 不使用密集文字

### 风格隔离

- 不混入科技感、霓虹、玻璃拟态风格
- 不混入复古、手绘、插画风格
- 保持简约、专业、现代感

## 质量检查清单

- [ ] 背景是否为纯白或浅灰
- [ ] 标题是否清晰可读
- [ ] 信息点是否简洁（每点 ≤ 15 字）
- [ ] 颜色是否统一（主色+辅色+强调色）
- [ ] 边框/卡片是否一致
- [ ] 无花哨装饰
